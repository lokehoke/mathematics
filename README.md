# Математика

Учебная книга **«Алгебра перед математическим анализом для Насти»** и архив открытых материалов математических олимпиад.

## Книга

[Читать PDF](rendered/algebra-for-nastya.pdf).

174 страницы, 22 главы, 549 задач с ответами и 70 теорем с доказательствами. Темы: аксиомы Пеано и индукция, арифметика, делимость, алгебра, корни произвольной натуральной степени, комбинаторика и бином Ньютона, уравнения, последовательности и прогрессии, функции, число e, логарифмы, гиперболические и обратные тригонометрические функции, множества и законы де Моргана. Добавлены неравенства и методы доказательств, векторы и матрицы, метод Гаусса, пределы и непрерывность, производные и линейное приближение, сравнения по модулю и диофантовы уравнения, полугруппы, моноиды, группы, кольца и поля.

- `sources/book/main.tex` — основной LaTeX-файл.
- `sources/book/chapters/` — главы.
- `sources/book/symbols.tex` — справочник обозначений.
- `sources/book/images/` — иллюстрации, точные графики и схемы.
- `sources/book/data/` — проверенные материалы для сборки глав.
- `rendered/algebra-for-nastya.pdf` — версия для чтения.
- `scripts/assemble_book.py` — сборка исходника из материалов; изменения отдельных глав следует переносить и в исходные данные, чтобы повторная сборка их не затёрла.

Оформление повторяет палитру обложки: кремовая бумага, тёмно-синий, приглушённый бирюзовый и охра. На обложке два котёнка: рыжий мальчик и белая девочка. 72 разные акварельные иллюстрации встроены в обычную полосу набора с обтеканием текстом. В основной части и ответах между иллюстрированными страницами остаётся не более двух страниц без котов; оглавление и таблицы обозначений оставлены без декоративных рисунков. Положение иллюстраций задаёт `sources/book/cats-flow.json`.

Нумерация страниц единая, арабская, начиная с оглавления; обложка без печатного номера. Справочник содержит 132 обозначения в 12 тематических группах, по одному обозначению в строке таблицы с границами. Страница «Как читать эту книгу», вводная фраза «Обозначения вводятся постепенно» и пометки «Из жизни» удалены. Сами задачи с бытовыми сюжетами сохранены.

Все 385 задач предыдущего издания и ответы к ним сохранены. Новые 164 задачи и теории глав 17–22 прошли независимое математическое ревью. Исправлены граничный случай модуля 1 при сокращении сравнений, условия общего домена для пределов, запись НОД для отрицательных коэффициентов и несколько переносов. Ранние ревью находятся в `research/book-*-audit-round2*.md`, ревью новых глав — в `research/review-new-chapters-*.md`.

### Сборка

Потребуются Python с `Pillow` и `pdfplumber`, Tectonic и, для компактной копии PDF, Ghostscript. При первой сборке Tectonic загружает TeX-пакеты.

```sh
python3 scripts/build_book.py
```

Скрипт заново собирает таблицы обозначений и LaTeX из данных, компилирует книгу и проверяет уникальность иллюстраций, пересечения с текстом и цветными рамками, границы полосы и полноту нумерации задач. Проверка записывается в `research/book-flow-layout-check.json`. Оригиналы рисунков сохраняются; только копия для чтения оптимизируется до 300 dpi (около 5 МБ), текст и графики остаются векторными. Экспорт дополнительно проверяет сохранность всех печатных символов на каждой странице. Без Ghostscript публикуется исходный PDF.

Можно также собрать `sources/book/main.tex` напрямую; при использовании XeLaTeX запустите `xelatex main.tex` дважды для обновления оглавления. Шрифты Noto Serif включены в проект, условия распространения находятся в `sources/book/fonts/LICENSE.txt`. Математический шрифт — Latin Modern Math.

Графики воспроизводятся командами `python3 scripts/make_figures.py` и `python3 scripts/make_extension_figures.py` с установленными matplotlib и numpy. Художественные иллюстрации созданы встроенным ImageGen; описания запросов и сведения о генерации находятся в `sources/book/images/prompts.json` и `sources/book/images/unique/*.json`. Исходники прозрачных PNG не обрезаются и не заменяются при оптимизации PDF.

## Олимпиады

Папки `olympiads/russia`, `olympiads/international` и `olympiads/university` содержат скачанные публичные материалы. Манифесты фиксируют источники, годы, типы документов и SHA-256. Загрузки возобновлены 22 октября 2026 года. Архив неполон: доступность и глубина официальных архивов различаются; найденные ссылки, скачанные задачи, решения, индексные страницы и прочие материалы учитываются отдельно. Олимпиадные задачи пока не включены в книгу.
