# Математика

Учебная книга **«Алгебра перед математическим анализом для Насти»** и архив открытых материалов математических олимпиад.

## Книга

[Читать PDF](rendered/algebra-for-nastya.pdf).

105 страниц, 16 глав, 385 задач с ответами: аксиомы Пеано и индукция, арифметика, делимость, алгебра, корни произвольной натуральной степени, комбинаторика и бином Ньютона, уравнения, последовательности и прогрессии, функции, число e, логарифмы, гиперболические и обратные тригонометрические функции, множества и законы де Моргана.

- `sources/book/main.tex` — основной LaTeX-файл.
- `sources/book/chapters/` — главы.
- `sources/book/symbols.tex` — справочник обозначений.
- `sources/book/images/` — иллюстрации, точные графики и схемы.
- `sources/book/data/` — проверенные материалы для сборки глав.
- `rendered/algebra-for-nastya.pdf` — версия для чтения.
- `scripts/assemble_book.py` — сборка исходника из материалов; изменения отдельных глав следует переносить и в исходные данные, чтобы повторная сборка их не затёрла.

Оформление повторяет палитру обложки: кремовая бумага, тёмно-синий, приглушённый бирюзовый и охра. 42 разные акварельные иллюстрации встроены в обычную полосу набора с обтеканием текстом. В основной части и ответах промежуток между иллюстрированными страницами не превышает трёх страниц; оглавление и таблицы обозначений оставлены без декоративных рисунков. Положение иллюстраций задаёт `sources/book/cats-flow.json`.

Проверены все 385 задач и ответов, 32 теоремы и их доказательства. Исправлены устаревшая ссылка на главу, разрывы коротких определений и условий задач, колонтитулы и положение иллюстраций. Математическое ревью и предложения по расширению находятся в `research/book-*-audit-round2*.md`. Новые главы пока не добавлены.

### Сборка

Потребуются Python с `Pillow` и `pdfplumber`, Tectonic и, для компактной копии PDF, Ghostscript. При первой сборке Tectonic загружает TeX-пакеты.

```sh
python3 scripts/build_book.py
```

Скрипт заново собирает LaTeX из данных, компилирует книгу и проверяет уникальность иллюстраций, пересечения с текстом и цветными рамками, границы полосы и полноту нумерации задач. Проверка записывается в `research/book-flow-layout-check.json`. Оригиналы рисунков сохраняются; только копия для чтения оптимизируется до 300 dpi (около 3,2 МБ), текст и графики остаются векторными. Без Ghostscript публикуется исходный PDF.

Можно также собрать `sources/book/main.tex` напрямую; при использовании XeLaTeX запустите `xelatex main.tex` дважды для обновления оглавления. Шрифты Noto Serif включены в проект, условия распространения находятся в `sources/book/fonts/LICENSE.txt`. Математический шрифт — Latin Modern Math.

Графики воспроизводятся командой `python3 scripts/make_figures.py` с установленными matplotlib и numpy. Художественные иллюстрации созданы встроенным ImageGen; описания запросов и сведения о генерации находятся в `sources/book/images/prompts.json` и `sources/book/images/unique/*.json`.

## Олимпиады

Папки `olympiads/russia`, `olympiads/international` и `olympiads/university` содержат скачанные публичные материалы. Манифесты фиксируют источники, годы, типы документов и SHA-256. Текущий архив неполон; по просьбе пользователя поиск и загрузки приостановлены до просмотра книги. Сохранённые очереди позволяют продолжить позже.
