# Математика

Учебная книга **«Алгебра перед математическим анализом для Насти»** и архив открытых материалов математических олимпиад.

## Книга

[Читать PDF](rendered/algebra-for-nastya.pdf).

114 страниц, 16 глав, 385 задач с ответами: аксиомы Пеано и индукция, арифметика, делимость, алгебра, корни произвольной натуральной степени, комбинаторика и бином Ньютона, уравнения, последовательности и прогрессии, функции, число e, логарифмы, гиперболические и обратные тригонометрические функции, множества и законы де Моргана.

- `sources/book/main.tex` — основной LaTeX-файл.
- `sources/book/chapters/` — главы.
- `sources/book/symbols.tex` — справочник обозначений.
- `sources/book/images/` — иллюстрации, точные графики и схемы.
- `sources/book/data/` — проверенные материалы для сборки глав.
- `rendered/algebra-for-nastya.pdf` — версия для чтения.
- `scripts/assemble_book.py` — сборка исходника из материалов; изменения отдельных глав следует переносить и в исходные данные, чтобы повторная сборка их не затёрла.

Оформление повторяет палитру обложки: кремовая бумага, тёмно-синий, приглушённый бирюзовый и охра. В полях через страницу размещены 57 акварельных котиков в трёх позах; пересечения с текстом и номерами страниц проверены.

### Сборка

Потребуется Tectonic или XeLaTeX. При первой сборке Tectonic загружает TeX-пакеты.

```sh
cd sources/book
tectonic main.tex
cp main.pdf ../../rendered/algebra-for-nastya.pdf
```

При использовании XeLaTeX запустите `xelatex main.tex` дважды для обновления оглавления. Шрифты Noto Serif включены в проект, условия распространения находятся в `sources/book/fonts/LICENSE.txt`. Математический шрифт — Latin Modern Math.

Графики воспроизводятся командой `python3 scripts/make_figures.py` с установленными matplotlib и numpy. Художественные иллюстрации созданы встроенным ImageGen; описание запросов находится в `sources/book/images/prompts.json`.

## Олимпиады

Папки `olympiads/russia`, `olympiads/international` и `olympiads/university` содержат скачанные публичные материалы. Манифесты фиксируют источники, годы, типы документов и SHA-256. Текущий архив неполон; по просьбе пользователя поиск и загрузки приостановлены до просмотра книги. Сохранённые очереди позволяют продолжить позже.
