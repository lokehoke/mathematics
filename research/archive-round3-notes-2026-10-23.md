# Третий проход: оставшиеся годы и альтернативные источники

**3549 новых уникальных документов**. Архив вырос с **6477 до 10023** материалов; документов с классифицированными решениями/ответами теперь **4377**. Три старых уникальных PDF с порогами дипломов «Физтеха» переведены в административные документы, поэтому чистый прирост составляет 3546. Оригиналы не удалены.

Проверены **11758** учитываемых физических файлов (5,47 ГБ): все SHA-256 совпадают, пропавших файлов нет. Прирост категории решений включает как новые загрузки, так и уточнение типов старых PDF.

## Что найдено и исправлено

- ВсОШ: из найденных 3131 ссылок сохранены 3083 файла. В этом проходе обработана ограниченная часть индексных страниц; 131 конкретный URL для продолжения сохранён в очереди.
- «Физтех»: официальный сайт использует HTML-оболочки `/folders/file/…`. Внутри находятся публичные PDF на сервере МФТИ. Учтены объединённые строки предметов и заголовки столбцов: 85 PDF скачаны из 89 ссылок. Материалы присутствуют за каждый год 2007–2026, но решения 2022 пока отдельно не подтверждены.
- Innopolis Open: 12 публичных PDF с официальной математической страницы; дополнительно 111 файлов из 123 ссылок вторичного архива. Восстановлены современные сезоны, включая 2025/26. Результаты и работы участников исключены из отбора.
- «Изумруд»: 47 файлов из 53 ссылок вторичного архива.
- «Бельчонок»: проверен новый официальный домен СФУ; из отдельного образовательного источника скачаны семь PDF для 2018–2021 годов. Файл 2018, подписанный источником как «Решения», на деле содержит только условия и не засчитан как решение.
- MathUs: авторские математические варианты для пробелов «Физтеха» (6 PDF), ПВГ (27), «Росатома» (11). Короткие числовые ответы не выданы за полный набор подробных решений.
- Турнир Ломоносова: только математические документы многопредметного архива — 16 PDF.
- RMM 2008/2010: найдены опубликованные PDF решений в сербском образовательном архиве. Скан 2010 года проверен распознаванием первого листа; исходник сохранён без изменений.
- BMO: сохранены пять опубликованных копий с решениями 2008, 2009, 2013, 2015, 2020 из открытого исследовательского зеркала с закреплённой версией; отдельно сборник сербской команды, содержащий BMO 2010. Зеркальные PDF являются опубликованными сторонними извлечениями из сборника, а не файлами с сервера организатора. Происхождение и проверенные заголовки решений записаны в манифесте.
- Исправлено смешение диапазона «10–11 класс» с сезоном 2010/11. У запросов PDF международного сборщика теперь есть ограничение полного времени передачи, включая DNS. Сборщик вторичного архива сохраняет промежуточный результат каждые 50 документов.

## Где ещё пробелы

- MEMO 2026: найдена официальная страница Problems с отдельными индивидуальным и командным вариантами, но загрузка страницы по-прежнему завершается таймаутом. Самих PDF в архиве пока нет.
- BMO: из ранее выявленных пробелов по решениям остался 2007 год.
- RMM: не подтверждены решения 2018–2020 и 2024–2026.
- Baltic Way: остаются решения 2009, 2019, 2022.
- «Бельчонок»: решения 2018. «Физтех»: решения 2022. ВсОШ: решения 2008; полное региональное покрытие пока не установлено.
- Innopolis Open: кандидатные годы без материалов 2016, 2019–2021. «Изумруд»: 2017–2020. ПВГ: 2012. «Росатом»: 2011–2012. У остальных архивов, в том числе вузовских, остаются пробелы из полной матрицы.
